Gemini (principal)

Cómo sacarla: aistudio.google.com → Get API key → Create API key. Tu suscripción de Gemini no cubre la API. Activa la facturación del proyecto para que Google no use las conversaciones de tus clientes y tengas límites más altos.

Groq (respaldo si Gemini falla)

Si Gemini está caído o saturado, se usa Groq con las mismas reglas. También transcribe los audios del reporte. Cómo sacarla: console.groq.com → API Keys → Create API Key (tiene plan gratuito).

CallMeBot: mensajes y llamada de emergencia

Servicio gratuito que te escribe por Telegram y, en emergencias, te hace una llamada de Telegram que suena aunque estés dormido.
  1. En Telegram, ponte un nombre de usuario (Ajustes → Nombre de usuario), por ejemplo @luis_skyguard.
  2. Abre @CallMeBot_txtbot en Telegram y envíale /start para autorizar las llamadas.
  3. Escribe tu usuario aquí abajo y guarda.
